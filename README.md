# フォルダ・ファイル一覧CSV作成ツール

Folder CSV Tool v1.1

指定フォルダ内の全サブフォルダとファイルを一覧化してCSVに保存するWindows用Pythonツールです。ローカルフォルダと、アクセス権のあるネットワーク共有（UNCパス）に対応します。

## 必要環境

Windows、Python 3（tkinter付き）。追加パッケージは不要です。

## 使い方

1. 配布ZIPを展開します。
2. `start.bat` をダブルクリックします。
3. 対象フォルダのパスを貼り付けるか「参照」で選択します。
4. 「CSV作成」を押し、対象フォルダの外に保存先を指定します。
5. 完了後、結果と取得エラーの有無を確認します。

## CSVの列

| 列 | 名称 | 内容 |
|---|---|---|
| A | 種別 | ファイル、フォルダ、リンク、不明 |
| B | 名前 | ファイル名・フォルダ名 |
| C | 相対パス | 対象フォルダからの相対パス |
| D | フルパス | 完全なパス |
| E | 拡張子 | 処理用。拡張子のみ。フォルダ・拡張子なしファイルは空欄 |
| F | サイズ_バイト | ファイルサイズ。フォルダは空欄 |
| G | 更新日時 | 実行PCのローカル時刻 |
| H | 表示分類 | 目視用。拡張子、フォルダ、拡張子なし、リンク、不明 |
| I | 状態 | 取得結果・省略の理由 |

CSVはUTF-8 BOM付きです。終了概要を同名の `.summary.txt` に、取得エラーがある場合は `.errors.csv` に保存します。

## コマンドライン

```bat
py -3 folder_csv.py --root "C:\GIS\Data" --output "C:\Work\inventory.csv"
```

## 動作上の注意

- 空フォルダ・隠し項目を含めて列挙します。対象フォルダ自体は行に含めません。
- 元データの内容は変更しません。ファイル品質を検査するツールではありません。
- 既存CSVは上書きしません。
- リンク・ジャンクションは記録し、循環防止のためリンク先の再帰走査を省略します。
- 取得エラー・リンク省略がある場合は結果に表示します。
- 実行中の追加・削除・更新に対する時点スナップショットではありません。
- 大容量の共有フォルダでは時間がかかります。

## 検証状況
