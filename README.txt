フォルダ・ファイル一覧CSV作成ツール v1.1

必要環境：Windows、Python 3（標準のtkinterを含む）。追加pipパッケージ不要。
Pythonが未導入の場合は、通常のWindows用PythonをTcl/Tk付きで導入してください。
QGIS付属Pythonだけではtkinterが使えない場合があります。

使い方
1. ZIPを展開します。ZIPの中から直接実行しないでください。
2. start.batをダブルクリックします。
3. 対象フォルダのパスを貼り付けます。前後のダブルクォーテーションは自動除去します。
4. 「CSV作成」を押し、保存先（デスクトップなど）を指定します。
5. 完了表示まで待ちます。別のパスで何度でも実行できます。

入力例
C:\GIS\Data
\\server\share\data

出力
*.csv：全階層のファイル／フォルダ一覧。空フォルダ・隠し項目を含む。
列：種別、名前、相対パス、フルパス、拡張子、サイズ_バイト、更新日時、表示分類、状態。
E列「拡張子」：処理用。ファイルの拡張子だけを記録し、フォルダ・拡張子なしファイルは空欄。
H列「表示分類」：目視用。拡張子、フォルダ、拡張子なし、リンク、不明を記録。
I列「状態」：取得済み、リンク先の再帰走査省略、取得エラーを記録。
*.summary.txt：対象パス、件数、取得エラー数、リンク省略数、終了日時。
*.errors.csv：取得エラーがある場合のみ生成。権限不足などを記録。
CSVはExcelで日本語を読みやすいUTF-8 BOM付き。フォルダのサイズは空欄。
対象フォルダ自体は一覧に含めず、その中の全項目を列挙します。

注意事項
・元データの変更や内容の読み込みは行いません。ファイルの品質検査は含みません。
・CSVは対象フォルダの外に保存してください。既存CSVへの上書きはしません。
・リンク／ジャンクションは一覧に記録しますが、循環防止のためリンク先を走査しません。
・エラーや省略がある場合は「全件取得済み」とみなさず、結果画面とログを確認してください。
・実行中にファイルが追加・削除・更新される場合、一覧は厳密な時点スナップショットにはなりません。
・NAS応答待ちには時間がかかる場合があります。処理中はウィンドウを閉じないでください。
・表示順はファイルシステムの列挙順です。必要ならExcelで相対パス順に並べ替えてください。

コマンドラインでも実行できます
py -3 folder_csv.py --root "対象フォルダ" --output "C:\Work\全リスト.csv"
終了コード：0=走査完了、2=取得エラーまたはリンク省略あり。

検証範囲
日本語パス、空フォルダ、隠しファイル、サイズ、リンク省略、取得エラー記録、上書き防止を
人工データで確認。Windowsの画面操作と社内NASでの実行は未確認です。
